Project Type: Academic Team Project

GetToWork is a web-based part-time job platform that connects students with businesses, helping students find flexible job opportunities while allowing businesses to recruit young talent
This Project was develop as a team project, focusing on building a user-friendly interface and implementing core job application functionalities

Features:
Job Listings — Browse available part-time jobs with relevant job information
Job Filtering — Filter job listings to find opportunities based on specific criteria
Job Application — Apply for suitable part-time jobs through the platform
Application History — Track previously submitted job applications
Job Management — Businesses can create, edit, and delete job listings
Application Management — Businesses can view applicants and accept or reject applications

Tech Stack:
Frontend: HTML, CSS
Backend: PHP
Database: MySQL
Development Environment: XAMPP
Database Management Tool: phpMyAdmin
Version Control: Git & GitHub

*This project was developed for academic purposes as part of a team assignment.
